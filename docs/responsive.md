# 响应式布局约定

项目保留 `src/layout/{user,vendor,admin}` 按角色划分的布局。设备尺寸是每个布局的呈现状态，不为同一业务页复制三套数据获取和表单逻辑。

| 设备 | 视口宽度 | 布局重点 |
| --- | --- | --- |
| 手机 | ≤767px | 单列内容、底部导航或抽屉导航、卡片化信息、弹窗适配安全区域 |
| iPad / 平板 | 768–1024px | 双列或紧凑网格、管理员抽屉侧栏、完整但收敛的操作区 |
| PC | ≥1025px | 多列布局、管理员固定侧栏、充分利用宽屏但限制内容最大宽度 |

纯外观差异使用 CSS 媒体查询。只有导航、交互流程或内容结构确实不同，才通过 `src/composables/useDevice.js` 切换组件。业务 API、状态和表单校验应放在共享页面中，避免 `HomeMobile.vue` 与 `HomeDesktop.vue` 各维护一份。

新增页面至少检查 375px、768px、1024px、1440px；检查文字溢出、表格滚动、弹窗、导航遮挡、触控目标和横竖屏。复杂数据表在小屏可使用横向滚动容器或独立卡片视图，不应让整页产生横向滚动。
